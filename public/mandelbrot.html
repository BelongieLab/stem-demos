The Mandelbrot Set

Scroll down to embark on a journey into infinite complexity arising from a very simple rule.

The Complex Plane

Imagine a flat, infinite grid. This is the complex plane.

Unlike a normal grid where coordinates are just two numbers $(x, y)$, here, every point represents a single Complex Number.

The horizontal axis is the real part, and the vertical axis is the imaginary part. We call a point here $c$.

A Simple Rule

To draw the Mandelbrot set, we pick a point $c$ on this plane and run it through a very specific, simple repeating process.

$$z_{n+1} = z_n^2 + c$$

We start with $z_0 = 0$.

  • First step: $z_1 = 0^2 + c = c$
  • Second step: $z_2 = c^2 + c$
  • Third step: $z_3 = (c^2 + c)^2 + c$

...and we keep doing this over and over.

The Escape Radius

As we repeat this calculation, one of two things happens to our sequence of numbers:

  1. It stays trapped: The sequence dances around, but never crosses a strict boundary.
  2. It escapes: Its distance from the center gets larger and larger, rocketing off towards infinity.

Mathematically, it is proven that once the magnitude (distance from zero) of our number is strictly greater than 2, it is guaranteed to accelerate toward infinity. We write this limit as:

$$|z| > 2$$

The Mandelbrot set is simply the collection of all starting points $c$ where the sequence never exceeds this boundary.

Escaping to Infinity

Let's test our rule by plugging in $c = 1$. We always start at $z_0 = 0$.

  • $z_1 = 0^2 + 1 = 1$
  • $z_2 = 1^2 + 1 = 2$
  • $z_3 = 2^2 + 1 = 5$

The sequence rockets outward. By step 3, its distance from the center is 5, safely past our red escape boundary of 2. It has escaped, so $c = 1$ is not in the Mandelbrot set.

A Trapped Orbit

Now, let's test $c = -1$.

  • $z_1 = 0^2 - 1 = -1$
  • $z_2 = (-1)^2 - 1 = 0$
  • $z_3 = 0^2 - 1 = -1$

The sequence endlessly bounces back and forth between $0$ and $-1$. It will never cross the escape radius, staying trapped forever. Therefore, $c = -1$ is in the Mandelbrot set.

Entering the Complex

What happens when we pick a point with an imaginary part? Let's test $c = -0.12 + 0.74i$.

The arithmetic works exactly the same, but now the values of $z$ jump across both axes of the 2D plane. Watch how this specific sequence settles into a beautiful, repeating triangular orbit.

Because this geometric orbit is perfectly stable and never spirals past the boundary of 2, this complex point also belongs to the set.

Coloring the Chaos

If we run this test for every single point on the complex plane...

Points that stay trapped (like $c = -1$ and $c = -0.12 + 0.74i$) are colored black. These form the main body of the set.

For the points that escape (like $c = 1$), we color them based on how many steps it takes for $|z|$ to strictly exceed $2$. A point that escapes in 3 steps might be dark blue, while one that takes 50 steps might be bright yellow.

Infinite Detail

Because we map the escape speed to a continuous color gradient, the boundaries of the set burst into intricate, swirling patterns.

The defining feature of a fractal like this is self-similarity. As you zoom in, you don't just find blur; you find more structure, more spirals, and even miniature copies of the entire set itself.
